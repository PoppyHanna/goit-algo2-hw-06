**Task 1**

Фільтр Блума дозволяє ефективно перевіряти унікальність елементів без збереження самих даних, що економить пам'ять. У завданні виконано кілька хеш-функцій для зменшення ймовірності хибно позитивних результатів.
Перевірка паролів відбувається швидко, навіть для великих наборів даних, оскільки операції з бітовим масивом мають низьку складність.
Код враховує некоректні або порожні паролі, що забезпечує стабільність роботи програми.
Основний недолік фільтра Блума - неможливість видалення елементів і наявність невеликої ймовірності помилки, коли новий пароль може бути помилково визначений як уже використаний.
